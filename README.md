# AntiGravity: Neon Pulse

[Play and install AntiGravity](https://shaunmcintyre813.github.io/mobile-arcade-game/)

Open the link in a mobile browser. Use the browser's **Install app** or **Add to Home Screen** option to keep it on your phone. The game is a web app; no separate app-store download is needed. After the first online visit, its service worker caches the game for offline play.

The source is available in this repository. To preview locally, run `npm run serve` and open `http://localhost:8080/`. Run `npm test` before publishing. A push to `main` publishes through the [GitHub Pages workflow](.github/workflows/pages.yml) after the tests pass.
